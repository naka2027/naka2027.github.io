System

从候选信号到真实订单

自动交易不是“有信号就下单”，而是一串可以互相否决的判断。

01Market

发现当前 BTC 5m window、token 与市场状态。

02Data

检查 freshness、continuity 与状态准备。

03Signal

多类信息形成方向候选，而非直接订单。

04Context

市场状态和后置规则可以 keep、adjust 或 STOP。

05Risk

动态仓位、账户、余额、allowance 与重复交易约束。

06Execution

下单、订单跟踪、确认、记录、持久化与下一市场。
